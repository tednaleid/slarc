# Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Mark a task's heading `[done]` and tick its steps in the same commit that finishes it.

**Goal:** A `slarc` CLI that pulls Slack channels, DMs, threads and single messages into an append-only JSONL archive with downloaded files and images, and offers `auth`, `list`, `search`, `sql` and a static HTML `export`.

**Architecture:** Hexagonal. A pure domain (links, envelopes, hashing, plain text, HTML rendering), a service layer with one module per CLI verb, ports in `src/slarc/ports.py`, and adapters for Slack, credentials, JSONL files, blobs and DuckDB. Every port except `QueryIndex` has an in-memory fake in `tests/fakes.py`; `QueryIndex` is tested through DuckDB over a temp archive.

**Tech Stack:** Python 3.14, uv, Typer + Rich, slack_sdk, httpx, msgspec, DuckDB, cryptography, keyring (secretstorage on Linux), Jinja2, Pygments, pytest, Hypothesis, ruff, ty.

**Spec:** `docs/specs/detailed-requirements.md`. Also read `GLOSSARY.md`, `docs/adr/`, `docs/specs/phase0-spike-findings.md`, and the spike fixtures in `tests/fixtures/spike/`.

## Global Constraints

- Every code file starts with two `# ABOUTME: ` lines saying what it does.
- `just check` passes before every commit. Use `just` recipes, never bare tools. Add a dependency with `uv add <pkg>` (or `uv add --dev`) in the task that first needs it.
- Domain (`src/slarc/domain/`) and service (`src/slarc/service/`) modules never import `slack_sdk`, `httpx`, `duckdb`, `keyring`, `secretstorage`, `os.environ`, `pathlib` I/O or `open()`. They may import `msgspec`, `jinja2`, `pygments` and the stdlib's pure modules.
- slarc never calls a Slack method that changes anything. The gateway adapter exposes read methods only.
- Live Slack calls during development: read-only, against `naleidworkspace` (team `T0CB5LYPVFA`) only. The desktop session holds tokens for other workspaces; never use them.
- Never print, log, write to a fixture, or include in an exception message any token, cookie or keychain secret. Types that hold secrets set `repr=False` on those fields.
- `ts` values are strings everywhere; never floats.
- JSON lines: UTF-8, compact (`separators=(",", ":")`), `\n`-terminated, `meta` first. Hash input: `json.dumps(subset, sort_keys=True, separators=(",", ":"), ensure_ascii=False).encode()` then sha256 hex.
- `fetched_at` is `YYYY-MM-DDTHH:MM:SSZ` (UTC, seconds). Run ids are `r_YYYYMMDDTHHMMSSZ`.
- User-facing errors are one or two plain sentences with no stack trace; exit code 1. Use glossary terms in messages and names.
- No emoji or em dashes in code, comments, output or docs.

## Review Focus

1. A huge first pull (100k messages) interrupted by Ctrl-C: the run line is still written with `backfill_complete: false` and `oldest_ts` set, and the next pull resumes older paging from there without re-appending lines. Test: Task 11 `test_interrupted_backfill_resumes_from_oldest_ts`.
2. A pull whose date range reaches past the free plan's retention: messages Slack no longer serves are never marked deleted. Test: Task 12 `test_full_pull_does_not_delete_below_oldest_returned`.
3. Running `slarc pull` in a clone where the session cannot see a tracked DM: a warning, `status: not_visible`, no `deleted` lines, and the other items still pulled. Test: Task 12 `test_not_visible_conversation_is_skipped_without_deletes`.
4. A Slack desktop app that is signed out, not installed, or whose keychain read is refused: one clear sentence naming the source and the `slarc auth --paste` fallback, never a traceback. Test: Task 4 `test_desktop_source_reports_missing_app_cleanly` and Task 8 `test_auth_failure_message_names_source`.
5. Message content the renderer has never seen (a new block or element type, a missing user, a deleted custom emoji): escaped text or `:name:`, never a crash. Test: Task 18 `test_unknown_block_type_renders_escaped_text` and `test_unknown_emoji_renders_colon_name`.

## Shared types

Defined once here; the owning task implements them. Later tasks use these names exactly.

```python
# domain/links.py
class MessageTs(str)                          # "1792410693.663869"; .from_permalink_digits("1792410693663869"); ordering by (int seconds, int micros)
@dataclass(frozen=True) class ConversationSel:  domain: str | None; channel: str | None; name: str | None; dm_user: str | None
@dataclass(frozen=True) class MessageSel:       domain: str | None; channel: str; ts: MessageTs; thread_ts: MessageTs | None
Selector = ConversationSel | MessageSel

# domain/envelope.py  (msgspec.Struct, kw_only=True, omit_defaults=True; field order is the spec's meta order)
Kind = Literal["message","deleted","user","emoji","conversation","bot","usergroup","file","image","run"]
class Meta:      schema: int = 1; kind: Kind; team; channel; ts; id; source_team; fetched_at; run; api; slarc; hash; plain; blob   # optional ones default None
class Envelope:  meta: Meta; object: dict | None = None

# domain/tracking.py  (msgspec.Struct, kw_only=True)
class TrackedItem:   team_id: str; kind: Literal["conversation","thread","message"]; channel: str; ts: str | None
                     since: str | None; until: str | None; newest_ts: str | None; oldest_ts: str | None
                     backfill_complete: bool; last_search_at: str | None; last_pull_at: str | None
                     status: Literal["ok","not_visible"]; last_read: dict[str, str]   # user_id -> ts
    key -> tuple[str, str, str, str]          # (team_id, kind, channel, ts or "")
class DownloadState: team_id: str; target_kind: Literal["file","image"]; target: str; url: str | None
                     status: Literal["pending","failed","forbidden","too_large","deleted","external"]; attempts: int; last_error: str | None
class RunRecord:     run: str; command: str; args: list[str]; started: str; finished: str | None; teams: list[str]
                     auth: list[dict]; counts: dict[str, float]; errors: list[dict]; tracked: list[TrackedItem]; downloads: list[DownloadState]

# ports.py
@dataclass(frozen=True) class Session:  team_id; domain; name; source: str; xoxc: str = field(repr=False); xoxd: str = field(repr=False)
@dataclass(frozen=True) class StoredMessage:  hash: str | None; thread_ts: str | None; fetched_at: str     # hash None = deleted
@dataclass(frozen=True) class DirectoryState: hash: str; blob: str | None
@dataclass(frozen=True) class DownloadJob:    team_id; target_kind; target; url; max_bytes: int; slack_auth: bool
@dataclass(frozen=True) class DownloadResult: job: DownloadJob; status: Literal["ok","failed","forbidden","too_large","deleted"]; sha256: str | None; size: int | None; content_type: str | None; error: str | None

class CredentialSource(Protocol):  def sessions(self) -> list[Session]
class SlackGateway(Protocol):
    def auth_test(self) -> dict
    def conversation_info(self, channel: str) -> dict                       # raises NotVisible
    def list_conversations(self) -> Iterator[dict]
    def history(self, channel: str, oldest: str | None, latest: str | None) -> Iterator[list[dict]]   # pages, newest first
    def replies(self, channel: str, ts: str) -> list[dict]                   # raises NotVisible, ThreadNotFound
    def search(self, query: str) -> Iterator[dict]                           # matches across pages
    def users(self) -> Iterator[dict]
    def usergroups(self) -> list[dict]
    def emoji(self) -> dict[str, str]
    def bot_info(self, bot_id: str) -> dict
    def file_info(self, file_id: str) -> dict                                # the "file" object; raises FileDeleted
class SlackConnector(Protocol):
    def sessions(self) -> list[Session]
    def connect(self, workspace: str) -> SlackGateway                         # domain or team_id; raises NoSession, AuthFailed
class Downloader(Protocol):  def fetch(self, jobs: list[DownloadJob], parallelism: int) -> Iterator[DownloadResult]
class BlobStore(Protocol):
    def write(self, chunks: Iterable[bytes]) -> tuple[str, int]               # (sha256, size)
    def exists(self, sha256: str) -> bool
    def read(self, sha256: str) -> bytes
class ArchiveStore(Protocol):
    def append(self, env: Envelope) -> None
    def flush(self) -> None
    def stored_messages(self, team: str, channel: str) -> dict[str, StoredMessage]
    def directory_state(self, team: str, kind: Kind) -> dict[str, DirectoryState]
    def directory_objects(self, team: str, kind: Kind) -> dict[str, dict]
    def tracked_items(self) -> dict[tuple[str, str, str, str], TrackedItem]
    def downloads(self) -> dict[tuple[str, str], DownloadState]
    def append_run(self, run: RunRecord, slarc_version: str) -> None
class QueryIndex(Protocol):
    def sql(self, query: str) -> tuple[list[str], list[tuple]]
    def search(self, text: str, in_channel: str | None, from_user: str | None, limit: int) -> list[SearchHit]
    def conversation_counts(self) -> dict[tuple[str, str], int]
    def messages(self, team: str, channel: str, since: str | None, until: str | None, include_deleted: bool) -> list[dict]
    def thread(self, team: str, channel: str, thread_ts: str, include_deleted: bool) -> list[dict]
class Clock(Protocol):  def now(self) -> datetime     # aware, UTC
class Reporter(Protocol):  def info(self, msg: str) -> None; def warn(self, msg: str) -> None; def progress(self, label: str, done: int, total: int | None) -> None

# errors (ports.py), all subclasses of SlarcError(Exception) with a user-facing str()
NoArchive, NoSession, AuthFailed(source, team), NotVisible(channel), ThreadNotFound(channel, ts), FileDeleted(file_id), CredentialReadError(source, step)
```

### Task 6: Envelopes, hashing and run records [done]

**Files:**

**Interfaces:**
